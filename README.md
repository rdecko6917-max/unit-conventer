# 📏 Unit Converter

A beginner-friendly Unit Converter built with Python.

## ✨ Features

- 🚗 Kilometers ⇄ Miles
- 🌡️ Celsius ⇄ Fahrenheit
- ⚖️ Kilograms ⇄ Pounds
- 📐 Centimeters ⇄ Inches
- 📏 Meters ⇄ Feet
- 🔁 Convert Again Option
- 💻 Beginner Friendly CLI

## ▶️ Run

```bash
python main.py
```
